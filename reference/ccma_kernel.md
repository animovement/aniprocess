# Construct a CCMA kernel of the given odd width.

Construct a CCMA kernel of the given odd width.

## Usage

``` r
ccma_kernel(width, type)
```

## Arguments

- width:

  Odd integer kernel width.

- type:

  Either `"hanning"` or `"uniform"`.

## Value

Numeric vector of length `width`, summing to 1.
